# 📝 Todo List Application (React)

A simple and efficient **Todo List application** built using **React**, **Context API**, **Local Storage**, and **Tailwind CSS**.  
This app allows users to **add, update, delete, and mark todos as completed**, with data persistence even after page reload.

---

## 🚀 Features

- ➕ **Add Todo** – Create new tasks easily  
- ✏️ **Update Todo** – Edit existing tasks (only if not completed)  
- 🗑️ **Delete Todo** – Remove tasks from the list  
- ✅ **Toggle Complete** – Mark tasks as completed using a checkbox  
- 🔒 **Edit Restriction** – Completed tasks cannot be edited  
- 💾 **Local Storage Support** – Todos persist even after page reload  
- 🎨 **Modern UI** – Styled using Tailwind CSS  
- 📱 **Responsive Design** – Works well on different screen sizes  

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **State Management:** Context API  
- **Styling:** Tailwind CSS  
- **Storage:** Browser Local Storage
